Projects

Deep RL PyTorch

https://github.com/jkulhanek/deep-rl-pytorch

The project is a library of deep reinforcement learning (DRL) algorithms written for PyTorch. Some of the implemented algorithms are PAAC, A3C, PPO, DQN, and Rainbow. The library is primarily used in other projects.
DRL, PyTorch

LemmaTag

https://github.com/jkulhanek/lemmatag

This project is an implementation of SoTA lemmatizer and tagger achieving 98.75% and 96.67% accuracies respectively on UD Treebank. The source code was written for TensorFlow 2. Pre-trained models are available for the Czech language.
NLP, TensorFlow 2

DMHouse

https://github.com/jkulhanek/dmhouse

The DMHouse project is a fork of the DMLab 3D environment published by DeepMind. In the simulator, there are new environments implemented which resemble office rooms. There is also a Python gym interface allowing the simulator to be used directly by DRL algorithms.
DRL, Bazel
